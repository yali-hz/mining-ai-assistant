# 应用目录

此目录包含可运行的「矿业智询」移动端 H5 Demo。使用原生 HTML、CSS、JavaScript，无第三方依赖，无需安装和构建。

## 运行与演示

在仓库根目录执行（需要 Node.js 18 或以上）：

```sh
node app/preview.mjs
```

电脑打开 http://localhost:5173，页面以手机宽度居中展示。手机与电脑处于同一局域网时，可访问 `http://电脑局域网IP:5173`（需要系统防火墙允许该端口）。手机以 375/390px 为主要设计基准，全屏显示。此服务仅用于本地静态预览，不是公网生产部署。

点击第一个示例问题，显示用户问题 → “正在查询…” → “已提交。2026年度储量年报已提交。”。另外两个示例支持时间和材料答复；也可手动输入、连续提问。Enter 发送，Shift+Enter 换行；查询期间不重复发送。

页面标明 Mock 演示，业务数据虚构，时间与材料不构成正式政策要求。没有调用现有 Mock API、Dify 或数据库。

## 文件与后续接口

- `templates/index.html`：单页面结构。
- `static/style.css`：移动端样式、桌面居中适配、安全区域。
- `static/chat.js`：消息展示、输入、加载与异常处理。
- `static/assistant.mjs`：统一 `sendMessage({ question })` 异步接口，返回 `{ text }`。下一阶段只需将该实现替换为同源后端调用；Dify 密钥不可放到前端。
- `preview.mjs`：仅提供上述静态文件的轻量预览服务，默认端口 5173，可用 `PORT` 环境变量调整。

## 检查

```sh
node --check app/static/chat.js
node --check app/static/assistant.mjs
node --check app/preview.mjs
```

原生静态页面无需打包构建。运行服务后检查三个示例、空白输入不发送、加载期间防重复提交，以及手机宽度下的滚动与底部输入区。
