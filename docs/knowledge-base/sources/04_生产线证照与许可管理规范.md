# 生产线证照与许可管理规范
本文件为矿业智询项目虚拟业务规则，仅用于产品测试。
## 生产线证照与许可：适用范围
本规范适用于生产线层面的证照和许可资料管理。
当前测试范围包括排污许可。
排污许可属于生产线许可类资料，不属于年度报告，也不属于专项方案与准入材料。
## 生产线证照与许可：排污许可证
生产线可以通过取得排污许可证满足当前虚拟测试规则下的排污许可要求。
排污许可证作为独立许可资料进行管理。
## 生产线证照与许可：排污登记
未采用排污许可证方式时，可以按照当前虚拟测试规则采用排污登记方式。
排污登记资料包括：
- 排污登记表
- 排污登记回执
采用排污登记方式时，排污登记表和排污登记回执应同时具备。
仅存在排污登记表或仅存在排污登记回执，均视为排污登记资料不完整。
## 生产线证照与许可：排污许可二选一规则
排污许可采用二选一规则。
方式一：具备排污许可证。
方式二：同时具备排污登记表和排污登记回执。
满足方式一或方式二中的任意一种完整形式，即视为生产线排污许可资料具备。
## 生产线证照与许可：资料缺失
同时满足以下情况时，判定为排污许可资料缺失：
- 未具备排污许可证
- 未同时具备完整的排污登记表和排污登记回执
