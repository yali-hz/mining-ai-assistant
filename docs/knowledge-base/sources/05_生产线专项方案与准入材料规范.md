# 生产线专项方案与准入材料规范
本文件为矿业智询项目虚拟业务规则，仅用于产品测试。
## 生产线专项方案与准入材料：适用范围
生产线除证照与许可外，还应根据监管要求形成相应专项方案和准入材料。
当前测试范围包括：
1. 安全生产“三同时”
2. 环境保护“三同时”
3. 生态修复方案
4. 水土保持方案
5. 节能减排方案
6. 林草占用手续
## 生产线专项方案与准入材料：安全生产“三同时”
当前虚拟测试规则下，安全生产“三同时”相关资料包括：
- 安全设施设计报告
- 安全设施验收意见
- 安全设施报告评审意见
- 安全设施报告批复
- 安全预评报告
- 安全预评报告评审意见
规定为必需的安全生产“三同时”资料应完整具备。
缺少必需资料时，判定为安全生产“三同时”资料不完整。
## 生产线专项方案与准入材料：环境保护“三同时”
环境保护“三同时”相关资料包括：
- 环评报告表
- 环评验收意见
- 环评批复
规定的环境保护“三同时”资料应完整具备。
缺少必需资料时，判定为环境保护“三同时”资料不完整。
## 生产线专项方案与准入材料：生态修复方案
生态修复方案相关资料包括：
- 生态修复方案报告
- 专家评审意见
当前虚拟测试规则下，两项资料共同构成生态修复方案资料。
缺少任意必需资料时，判定为生态修复方案资料不完整。
## 生产线专项方案与准入材料：水土保持方案
水土保持方案相关资料包括：
- 水土保持方案报告
- 水土保持设施验收报告
- 水土保持方案批复
规定资料全部存在时，视为水土保持方案资料齐全。
## 生产线专项方案与准入材料：节能减排方案
当前虚拟测试范围内，节能减排方案主要资料包括：
- 节能报告
## 生产线专项方案与准入材料：林草占用手续
当前虚拟测试范围内，林草占用手续主要资料包括：
- 占用审批文件
## 生产线专项方案与准入材料：资料归属
专项方案与准入材料按照具体生产线独立管理。
同一矿山下不同生产线之间的专项方案与准入材料不得相互替代。
