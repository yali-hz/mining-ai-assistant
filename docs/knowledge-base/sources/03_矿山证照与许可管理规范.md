# 矿山证照与许可管理规范
本文件为矿业智询项目虚拟业务规则，仅用于产品测试。
## 矿山证照与许可：适用范围
本规范适用于矿山层面的证照、许可和权属资料管理。
当前测试范围包括：
1. 采矿权证书
2. 不动产权证
3. 安全生产许可
4. 取水许可
5. 项目用地相关资料
证照与许可类资料不同于年度报告。
证照与许可主要关注资料是否存在、是否完整、是否有效以及是否满足对应组合规则。
## 矿山证照与许可：采矿权证书
采矿权证书属于矿山核心证照。
主要监管信息包括：
- 采矿许可证号
- 采矿权人
- 有效期开始时间
- 有效期结束时间
- 发证级别
当前日期处于采矿权证书有效期内时，证书视为有效。
当前日期超过采矿权证书有效期结束时间时，证书视为过期。
距采矿权证书有效期结束不足90天时，可标记为临期。
距采矿权证书有效期结束不足30天时，可标记为即将到期。
## 矿山证照与许可：不动产权证
不动产权证属于矿山权属类资料。
不动产权证主要检查：
- 是否存在对应资料
- 是否关联当前矿山
- 是否存在有效记录
## 矿山证照与许可：安全生产许可
当前虚拟测试规则下，安全生产许可采用二选一方式。
满足以下任意一种情况，即视为安全生产许可资料具备：
- 已具备安全生产许可证
- 已具备符合当前测试规则的小危行业相关证明
安全生产许可证和小危行业相关证明均缺失时，判定为安全生产许可资料缺失。
## 矿山证照与许可：取水许可
取水许可资料包括：
- 取水许可证
- 取水许可批复
当前虚拟测试规则要求同时检查取水许可证和取水许可批复。
缺少其中任意一项时，判定为取水许可资料不完整。
## 矿山证照与许可：项目用地资料
项目用地相关资料包括：
- 建设项目用地资料
- 土地租用资料
具体需要哪类项目用地资料，应根据矿山实际用地方式确定。
## 矿山证照与许可：检查原则
矿山证照与许可主要从以下维度检查：
1. 证照或许可资料是否存在
2. 必需资料是否完整
3. 存在有效期的证照是否仍在有效期内
4. 证照或许可是否与当前矿山对应
5. 是否满足二选一、多项组合等业务规则
