\# 年度报告逾期与补报规则

本文件为矿业智询项目虚拟监管规则，仅用于产品测试，不代表真实法律法规或行政监管要求。

\## 年度报告逾期判断：所需信息

判断年度报告是否逾期，应结合报告年度、报告类型、应提交截止日期、当前提交状态、实际提交日期和当前日期。年度报告的“未提交”和“逾期”属于不同状态，报告尚未提交并不代表已经逾期。

\## 年度报告逾期判断：正常提交

当年度报告已经提交，并且实际提交日期不晚于规定截止日期时，判定为正常提交。典型情况包括截止日期前已经提交、按时报送、在规定期限内完成提交、实际提交日期早于或等于截止日期。对应状态为：已提交。

\## 年度报告逾期判断：尚未到期未提交

当年度报告尚未提交，但当前日期还没有超过规定截止日期时，判定为尚未到期未提交。典型情况包括还没有提交但还没到截止日期、当前仍在报送期限内、尚未到期、报告待提交但暂未超期。对应状态为：未提交，但尚未逾期。

\## 年度报告逾期判断：逾期未提交

当年度报告尚未提交，并且当前日期已经超过规定截止日期时，判定为逾期未提交。典型情况包括已经过了截止日期但仍未提交、超过报送期限仍未报送、已到期且未提交、当前日期已经晚于截止日期但报告仍为空缺。对应状态为：已逾期未提交。

\## 年度报告逾期判断：逾期后补交

当年度报告在规定截止日期之后才完成提交时，判定为逾期后补交。典型情况包括超过截止日期后才提交、过了报送期限才补交、截止日前未提交但之后已经补交、实际提交日期晚于规定截止日期、报告晚交但当前已经提交完成、逾期之后完成补报。对应状态为：逾期后补交。逾期后补交表示当前报告已经提交，但该年度存在历史逾期情况。

\## 年度报告逾期判断：状态区分

年度报告四种状态的核心区别如下：已提交，是指已经提交且提交时间不晚于截止日期；未提交但尚未逾期，是指尚未提交但当前日期未超过截止日期；已逾期未提交，是指尚未提交且当前日期已经超过截止日期；逾期后补交，是指已经提交但实际提交日期晚于截止日期。判断时应同时关注“是否已经提交”和“是否超过截止日期”。

\## 年度报告逾期判断：跨年度规则

不同年度的年度报告分别独立判断。2025年度储量年报逾期，不代表2026年度储量年报一定逾期。2026年度储量年报正常提交，也不能消除2025年度储量年报的历史逾期记录。
