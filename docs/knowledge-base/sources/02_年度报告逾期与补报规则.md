# 年度报告逾期与补报规则
本文件为矿业智询项目虚拟监管规则，仅用于产品测试，不代表真实法律法规或行政监管要求。
## 年度报告逾期判断：所需信息
判断年度报告是否逾期，应结合以下信息：
1. 报告年度
2. 报告类型
3. 应提交截止日期
4. 当前提交状态
5. 实际提交日期
6. 当前日期
年度报告的“未提交”和“逾期”属于不同状态。报告尚未提交，并不代表报告已经逾期。
## 年度报告逾期判断：正常提交
同时满足以下条件时，判定为正常提交：
- 报告已经提交
- 实际提交日期不晚于规定截止日期
对应状态为：已提交。
## 年度报告逾期判断：尚未到期未提交
同时满足以下条件时，判定为尚未到期未提交：
- 当前报告尚未提交
- 当前日期尚未超过规定截止日期
对应状态为：未提交，但尚未逾期。
## 年度报告逾期判断：逾期未提交
同时满足以下条件时，判定为逾期未提交：
- 当前报告尚未提交
- 当前日期已经超过规定截止日期
对应状态为：已逾期未提交。
## 年度报告逾期判断：逾期后补交
同时满足以下条件时，判定为逾期后补交：
- 报告已经提交
- 实际提交日期晚于规定截止日期
对应状态为：逾期后补交。
逾期后补交表示当前报告已经完成提交，但该年度仍存在历史逾期记录。
## 年度报告逾期判断：跨年度规则
不同年度的年度报告分别独立判断。
2025年度储量年报逾期，不代表2026年度储量年报一定逾期。
2026年度储量年报正常提交，也不能消除2025年度储量年报的历史逾期记录。
