# 生产线合规状态判定规则
本文件为矿业智询项目虚拟监管规则，仅用于产品功能和合规判断测试，不代表真实行政执法标准。
## 生产线合规判断：判定范围
生产线合规状态从以下维度进行检查：
1. 生产线证照与许可
2. 生产线年度报告
3. 专项方案与准入材料
4. 生产线资料齐全性
生产线综合状态应在各维度分别检查后进行汇总。
## 生产线合规判断：证照与许可
生产线当前重点检查排污许可。
排污许可采用二选一规则。
满足以下任意一种完整形式，即视为生产线排污许可资料具备：
- 具备排污许可证
- 同时具备排污登记表和排污登记回执
排污许可证和完整的排污登记资料均不具备时，判定为排污许可资料缺失。
仅存在排污登记表或仅存在排污登记回执时，判定为排污登记资料不完整。
## 生产线合规判断：年度报告
生产线当前测试范围包括：
1. 卤水监测年报
2. 年度开发利用报告
3. 国情调查报告
每条生产线、每个年度分别进行检查。
对应年度报告已经在规定截止日期前完成提交时，年度报告状态正常。
对应年度报告尚未提交，但当前日期尚未超过截止日期时，属于年度报告待办。
已经超过截止日期但报告仍未提交，或者报告在截止日期之后补交时，属于年度报告异常。
不同年度的生产线年度报告不得相互替代。
## 生产线合规判断：专项方案与准入材料
生产线专项方案与准入材料包括：
- 安全生产“三同时”
- 环境保护“三同时”
- 生态修复方案
- 水土保持方案
- 节能减排方案
- 林草占用手续
每一类专项方案按照对应资料规则检查完整性。
缺少规定的必需资料时，对应专项方案判定为资料不完整。
## 生产线合规判断：资料齐全性
生产线资料齐全性应检查以下三类资料。
证照与许可类：
- 排污许可
专项方案与准入材料类：
- 安全生产“三同时”
- 环境保护“三同时”
- 生态修复方案
- 水土保持方案
- 节能减排方案
- 林草占用手续
年度报告类：
- 卤水监测年报
- 年度开发利用报告
- 国情调查报告
当前要求的必需资料均存在并满足对应完整性要求时，判定为资料齐全。
存在必需资料缺失或组合资料不完整时，判定为资料不齐全。
关键业务数据不足时，判定为暂无法判断资料齐全性。
## 生产线合规判断：综合状态
生产线综合状态分为正常、存在待办、存在异常和暂无法判断。
### 正常
同时满足：
- 排污许可满足当前规则要求
- 专项方案与准入材料完整
- 年度报告无逾期情况
- 当前要求的必需资料齐全
### 存在待办
不存在明确异常，但存在尚未完成且仍在规定期限内的事项。
例如某项年度报告尚未提交，但当前尚未超过截止日期。
### 存在异常
存在以下任意一种情况：
- 排污许可资料缺失
- 排污登记资料不完整
- 专项方案必需资料缺失
- 年度报告已经逾期
- 当前要求的其他必需资料缺失
### 暂无法判断
缺少关键业务数据，导致一个或多个重要合规维度无法完成判断。
