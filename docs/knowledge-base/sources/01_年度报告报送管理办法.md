# 年度报告报送管理办法
本文件为矿业智询项目虚拟监管规则，仅用于产品功能、RAG和合规判断测试，不代表真实法律法规或行政监管要求。
## 年度报告管理：适用范围
本办法用于规范矿山及生产线年度监管报告的报送管理。
当前测试范围包括：
1. 储量年报
2. 卤水监测年报
3. 年度开发利用报告
4. 国情调查报告
年度报告按照具体业务对象和具体年度独立管理。
## 年度报告管理：储量年报
储量年报的关联对象为矿山。
每座矿山每个年度应形成一条独立的储量年报记录。
同一矿山不同年度的储量年报不得相互替代，不同矿山之间的储量年报不得共用。
## 年度报告管理：卤水监测年报
卤水监测年报的关联对象为生产线。
每条生产线每个年度应形成一条独立的卤水监测年报记录。
同一矿山下不同生产线的卤水监测年报分别管理，不得相互替代。
## 年度报告管理：年度开发利用报告
年度开发利用报告的关联对象为生产线。
每条生产线每个年度应形成一条独立的年度开发利用报告记录。
不同年度、不同生产线之间的年度开发利用报告不得相互替代。
## 年度报告管理：国情调查报告
国情调查报告的关联对象为生产线。
每条生产线每个年度应形成一条独立的国情调查报告记录。
## 年度报告管理：虚拟报送时限
矿业智询项目当前使用以下虚拟报送时限：
| 报告类型 | 虚拟报送截止日期 |
| --- | --- |
| 储量年报 | 次年3月31日前 |
| 卤水监测年报 | 次年4月30日前 |
| 年度开发利用报告 | 次年5月31日前 |
| 国情调查报告 | 当年12月31日前 |
储量年报的虚拟测试截止日期为次年3月31日。
卤水监测年报的虚拟测试截止日期为次年4月30日。
年度开发利用报告的虚拟测试截止日期为次年5月31日。
国情调查报告的虚拟测试截止日期为当年12月31日。
## 年度报告管理：报送状态
年度报告状态包括：
- 未提交
- 已提交
- 已逾期未提交
- 逾期后补交
年度报告状态应结合报告年度、截止日期、实际提交日期和当前日期进行判断。
## 年度报告管理：年度数据口径
年度报告必须按照具体年度查询和判断。
查询2026年度储量年报时，只能使用2026年度对应记录，不得使用2025年度或其他年度报告替代。
